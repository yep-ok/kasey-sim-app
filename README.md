# Kasey Sim - 3D Swing Lab

Live app: https://yep-ok.github.io/kasey-sim-app/

Built site only (generated). Drop in a golf swing video and get a 3D avatar, swing positions P1-P10 and biomechanics metrics. Pose estimation runs in your browser; videos are never uploaded.
